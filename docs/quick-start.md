# 快速上手指南

## 30秒开始

1. **选择你的 AI 工具**：ChatGPT / Claude / WorkBuddy / 其他
2. **获取 System Prompt**：打开 `prompts/universal-prompt.md`，复制 "## System Prompt" 以下的内容
3. **粘贴到你的 AI 工具**：
   - ChatGPT → Settings → Custom Instructions → 第二个框
   - Claude → Projects → System Prompt
   - WorkBuddy → 放入 skills 目录
4. **开始对话**：直接描述你的问题，AI 会自动匹配合适的框架

## 常见问题

**Q：我需要读完《鬼谷子》原书才能用吗？**
A：不需要。每个框架文件里都有原文和白话对照，直接用就行。

**Q：这些框架能用在亲密关系中吗？**
A：大部分框架的边界部分都明确标注了"亲密关系慎用"。谋略工具用在家里会侵蚀信任基础。

**Q：AI 不按框架回答怎么办？**
A：在 prompt 里强调"请严格按照框架匹配→分析→可执行建议→边界提醒的格式回答"。或者在对话中追问"你用的是哪套框架？"

**Q：可以同时用多套框架吗？**
A：可以，而且推荐。复杂问题通常需要多框架组合。详见 SKILL.md 中的"多框架组合"部分。
